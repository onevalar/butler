# 正式版截图入口

两个 plist 是可审阅的快捷指令源文件，基于用户在 iPhone 上验证过的实验入口导出。只替换最后的接收动作、设置录入方式并保留隐藏控制中心、等待一秒、截屏的顺序。没有网址、密钥或预置任务。`Butler/Resources` 中对应的 `.shortcut` 是 Apple 签名的安装文件，由 Xcode 自动复制进应用。

修改源文件后，在已登录 iCloud 的 Mac 上重新签名：

```sh
python3 scripts/shortcuts/sign.py
```

签名成功只证明模板格式通过系统签名服务；不证明 iPhone 端导入、权限弹窗或语音启动通过验收。真机检查：设置「从其他 App 采集」点安装，在系统打开菜单选择「快捷指令」，分别导入两个模板；绑定控制中心；在其他 App 触发并确认截图正确；分别补充文字和语音，核对后手动发送。还需检查冷启动、取消再触发、有旧草稿、附件已满及回复期间的等待行为。发送前不能调用模型或写入任务/库存。

安装必须使用系统文档打开菜单（`com.apple.shortcut`），不能把 Quick Look 预览当作安装：预览页没有添加按钮，并可能把 App Intent 动作显示为未知。交给系统应用只表示请求导入，不证明已经安装；不能提前显示安装成功。
