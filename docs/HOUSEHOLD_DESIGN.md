# 家庭共享（多人共用）设计

用户确认的方案（2026-10-09）。实现分三步：① 共享物品（已完成）② 共享与指派任务（已完成）③ 管家多人化（已完成）。

## 已确定的原则
- 全家都是 iPhone：用 iCloud 共享（CKShare 整区共享），不自建服务器、不注册账号。创建者的 iCloud 存家庭资料；家人用自己的 Apple ID 加入；一个人只加入一个家庭；只有创建者能邀请；退出或解散时每个人保留一份当时的东西。
- 每件事三个属性：谁能看到（只有我 / 全家 / 指定的人 / 对某人隐藏）、谁负责、提醒谁。
- 属性的来源优先级：句子里说的 > 个人规则 > 家庭规则 > 管家按内容判断 > 保守默认（任务只有我，物品全家）。新情况由管家先判断，直接给结论；只有涉及隐私又拿不准时才问一句。默认不是写死的。
- 规则以对话修改为主，必要时点选项；设置里有一页规则列表可查可改。“分工”不单独做页面，就是说到具体人的家庭规则，管家也会从使用中提议。
- 提醒的规矩可选、用一句话设定：有人处理了其他人不再提醒（默认开）、没人处理就提醒下一个人、免打扰时段。
- 全家可见的任务被完成后不消失：标明谁完成、几点、怎么完成，点错可改回，记录谁改的。
- 模型：每个人用自己的订阅登录（2026-10-10 用户决定）；不做家庭共享模型。
- 首页提醒按人生成：只含他看得到、跟他有关的；别人做了什么只在能避免重复或需要配合时提；按钮只给需要自己动手的事；指派给别人的事可“提醒他一下”。

## 第一步（共享物品）的实现
- 家庭的共享物品走独立 CloudKit 区 `ButlerHouseholdV1-<id>`（创建者私有库，家人经共享库访问），复用 `SyncStore` 的修订链同步；记录种类为 `inventory`（附 `ItemSharing`：范围、对谁隐藏、谁记的、谁改的）和 `member`。
- 本机自己的同步（`ButlerSyncData`）不再携带家庭共享的物品，避免同一件东西走两条路；个人物品仍走本人的私有区。
- 建家庭 / 加入前先自动备份；`HouseholdClassifier` 判断哪些留给自己（个人药品、护肤、礼物等），家里共用的药（感冒药、创可贴）仍共享；加入时同名物品与家里已有的合并，只给一张结果卡。
- 对某人隐藏只在对方手机上不显示、不给模型看（数据仍在同一共享区，不是加密隔离）。
- 邀请用系统 `UICloudSharingController`；接受邀请经 `ButlerSceneDelegate`（Info.plist `CKSharingSupported`）。
- 对话工具 `propose_item_sharing` 修改谁能看到，确认后生效；`current_context.household` 告诉模型家里有谁、当前是谁。

## 第二步（共享与指派任务）的实现
- 任务带 `TaskSharing`：范围（personal / household / people）、对谁隐藏、创建者、负责人、提醒谁（空=负责人，没人负责就是创建者）。交给别人或提醒别人的任务自动对对方可见（`normalized()`）。
- 非 personal 的任务走家庭区（记录种类 `task`），本人私有同步不再携带。看不到的任务放在 `HouseholdStore.hiddenTasks`，不进列表、提醒和模型，但仍原样参与同步，避免被误删。
- 每部手机只排“提醒名单里有我”的家庭任务（`ReminderStore.remindsHere`）；有人完成后状态同步过来，其他手机的提醒自然撤掉。
- 操作记录 `ReminderActivity.by` 记下是谁做的；完成不删除，首页已完成显示“· 妈妈完成”，任务页有“家人”区（谁能看到 / 谁负责 / 到点提醒 / 谁记的），可以改回，改动写进“做过什么”（用第三人称写，所有人读起来一致）。
- 收到别人交给自己的事立即本地通知“老公交给你一件事”；自己创建的事被别人完成时通知“老婆完成了”。
- 家庭区变化通过 CloudKit 订阅静默推送唤醒手机同步（`aps-environment` + `remote-notification`），App 关着也能收到指派。
- 对话：`propose_reminder` / `propose_task_plan` 带 `family`，管家按句子 > 家庭规则 > 内容判断直接给结论；`propose_task_sharing` 修改；确认卡片上一行“全家可见 · 交给妈妈”可点开直接改，改动会告诉管家以便提议记成规则。
- 管家日记加入家人做的事（“老婆完成了 交水费”）。

## 第三步（管家多人化）的实现
- 首页提醒按人生成：候选事项带 family（交给谁/谁交给你）和 responsible；家人负责的事只在需要配合、避免重复或过时没人处理时提，按钮只能是“提醒他一下”(nudge) 或先放放，不能替对方点完成。
- “提醒他一下”：在任务上记一条 nudged 记录，经家庭同步到对方手机后立即通知“老公提醒你”；10 分钟内不重复。首页卡片、长按菜单、任务页、对话（propose_nudge）都能发。
- 没人处理时：`TaskSharing.escalateTo/escalateAfter`，只对一次性任务；接手人的手机预排“老婆还没处理：交水费”，任务完成后同步过来自动撤掉。
- 免打扰：`HouseholdMember.quiet`，随成员同步；家人设给你的提醒、指派通知、提醒他一下在时段内延后到结束，自己定的提醒照常。
- 规则：家里的规则（`HouseholdRule`，记录种类 `rule`，全家同步）和只对我的规则（只存本机，退出家庭也保留）。管家按“这句话 > 只对我 > 家里 > 自己判断 > 保守默认”照做；对话 propose_household_rule 增删，设置 › 家庭 › 共享与提醒规则 可查看、添加、左滑删除，并设免打扰。
- 不做家庭共享模型（2026-10-10 用户决定）：模型登录是个人 ChatGPT 订阅，共享等于把个人令牌复制到家人手机，涉及账号条款和令牌轮换冲突。每个人用自己的订阅；以后若改用按量付费的接口密钥，再考虑家庭共享开关。

## 验收注意
- 需要两个不同 Apple ID 的 iPhone 实测邀请、加入、同步、指派、完成回执、推送、退出、解散。模拟器未登录 iCloud，只能验证界面。
- 调试安装用 CloudKit 开发环境，TestFlight/App Store 用生产环境，两边不能互通；正式测试前须在 CloudKit Console 把开发环境的结构部署到生产环境。
