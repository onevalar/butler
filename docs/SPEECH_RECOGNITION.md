# 语音识别配置与工作方式

更新：2026-09-29。此功能已加入本地源码；不代表已发布 TestFlight。

## 使用

进入“管家与设置 → 语音识别”，选择苹果语音识别或自定义语音模型，点击“保存语音设置”。下一次录音生效；水晶球、对话框麦克风和独立语音试用页使用同一配置。

默认使用苹果 Speech 框架，优先 iOS 26 SpeechAnalyzer；模块不可用时回退 SFSpeechRecognizer，可能使用苹果在线服务，并非保证完全离线。苹果模式支持边说边显示文字。

自定义模式填写 HTTPS Base URL、模型名称和 API Key。普通转写模型使用 OpenAI 兼容的 multipart `/audio/transcriptions`：上传 m4a 文件，指定 `model` 和 `response_format=json`，读取响应的 `text`。`gpt-live-transcribe` 自动选择下述实时通道。只有聊天接口或采用其他协议的模型不能直接接入。

## AiHubMix

根据其[快速开始](https://docs.aihubmix.com/cn/quick-start)、[转写接口](https://docs.aihubmix.com/cn/api-reference/openai-compatible/create-transcription)与[语音转文本指南](https://docs.aihubmix.com/cn/api/STT)，可使用：

| 配置 | 值 |
|---|---|
| Base URL | `https://aihubmix.com/v1` |
| 模型示例 | 实时：`gpt-live-transcribe`；文件转写：`gpt-4o-mini-transcribe`、`whisper-1` |
| API Key | 用户在 AiHubMix 生成的密钥，在手机设置中输入 |

AiHubMix 备用域名 `https://api.inferera.com/v1` 也可使用。同一服务只填主域名或备用域名时自动补全 `/v1`，旧版漏写路径的凭据在原主机内兼容，绝不跨主机迁移密钥。不要填写 `/chat/completions`。

### 实时通道

`gpt-live-transcribe` 按[官方实时转写文档](https://docs.aihubmix.com/cn/api/realtime-transcription)连接 `wss://所填主机/v1/realtime?intent=transcription&model=gpt-live-transcribe`，以 Authorization Bearer 鉴权。配置 PCM16、24000Hz、单声道，`languages=["zh","en"]`、`turn_detection=null`、近场降噪；网关接受 session.update 后按顺序发送音频，增量文字及时上屏。松手停止麦克风、发送剩余音频并 commit，最终完整结果替换增量文字，避免重复发送。

设置提供“检查已保存的实时语音连接”：只验证鉴权和会话配置，不采集或上传音频，不等同实际识别测试。余额/模型限制/IP白名单等错误按已知类别显示，不回显服务端任意文本或密钥片段。

## 交互与边界

- 短按水晶球打开文字输入；长按收音，文案为“松开发送，上滑取消”。长按松手转写成功后发送一次；对话框麦克风停止后文字留在草稿供修改。
- 文件模式录音时只在本机保存临时音频，正常结束才上传；上滑取消不上传。实时模式在说话时持续上传，上滑取消立即停麦克风、断开连接并丢弃文字；已经到达服务器的音频无法撤回。退出、后台、错误与超时都清理会话，迟到回调不能污染下次输入。
- 自定义模式每次最长2分钟，超时取消并提示分段输入。请求超时40秒、整体收尾保护45秒，等待时可取消。苹果收尾仍为3秒。
- 文件模式松手后有上传及服务处理时间；实时模式边传边识别，实际时延取决于网络和服务端，不能承诺比苹果更快。没有改变现有液态玻璃、连续触感或两种按压操作。
- API Key 保存在此设备系统钥匙串，不写入偏好或备份，不交给对话模型；凭据绑定接口地址，更换地址须重新填写。关闭自定义模式可保留配置，亦可明确移除配置与密钥。
- 不跟随服务重定向，不自动切换服务。错误提示不展示服务原始响应或密钥。临时录音在正常完成、取消或失败后删除。

## 验证

初版57项相关测试通过。实时接入新增协议、PCM转换、顺序发送、增量/最终结果、取消与错误脱敏测试，本轮36项通过。手机使用原已保存的密钥，验证备用域名的实时鉴权与会话配置已成功；密钥未导出。先前“拒绝授权”不能据此认定密钥错误，当前已确认配置缺少 `/v1` 且实时模型被错误发到文件接口。真机麦克风与手感仍需用户实测。

随后通过手机发送约2.09秒本地合成语音“这是一段语音识别测试”，收到10次文字更新，最终结果匹配测试句。测试未访问麦克风、未发送用户录音、未向管家对话发消息；临时测试音频自动删除。此项验证真实协议及识别返回，不替代真机麦克风/触觉体验验收。
