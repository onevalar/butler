# 小当家采集实验（可独立删除）

目标：验证「其他 App → 控制中心 → 截图 → 自由说明意图 → 本机保存」是否足够方便。
这不是正式版功能，也不是完整小当家的复制品。它不理解图片、不执行指令、不写库存/提醒/日历。

## 隔离范围

- 独立 Xcode 工程、独立安装标识 `com.anvalar.Butler.CaptureLab`、名称“小当家采集实验”；可与正式版并存。
- 不引用正式版源码、App Group、数据库、钥匙串共享组、CloudKit 或其他扩展。
- 只写自己的 Application Support/CaptureLab，明确排除系统备份。不会请求相册权限，不读取“最新截图”。
- 只有配置为“语音”的新交接才尝试自动启动麦克风；手动打开和重启恢复旧草稿不会自动录音。
- App 内识别强制设备端中文，不保存音频、不做服务器识别回退；权限拒绝或设备不支持时打字。**这不代表正式版语音的能力或速度。** 如使用系统键盘自带听写，遵循苹果键盘自身的隐私设置。
- 图片直接由快捷指令传入，读取后立即复制到实验容器；原始输入上限 20 MiB，缩小到最长边 1600 像素后 JPEG 不超过 4 MiB。不是原图归档，细小订单文字可能受影响，实测时需检查。
- 未完成草稿存在时，新的交接报错，保留旧内容。不是后台采集队列；保存或删除后可接收下一张。

## 先做不需要安装 App 的截图验证

在 iPhone 的“快捷指令”中新建“采集截图验证”，按顺序配置：

1. **显示控制中心 / Show Control Center**：把操作设为**隐藏**，不要用切换。
2. **截屏 / Take Screenshot**。
3. **快速查看 / Quick Look**：明确使用第 2 步的“截屏”结果。

控制中心长按空白 → 添加控制 → 快捷指令 → 选择“采集截图验证”。不要选只有打开 App 的控制。
在淘宝商品、淘宝订单、微信、Safari 四种页面各做 5 次，共 20 次，记录截到原页面、控制中心、快捷指令界面还是空白。
初次运行的权限/隐私提示单独记，不计入熟练操作耗时。

若截到控制中心的消失动画，在第 1、2 步间加“等待 1 秒”重试并记录增加的时间，不默认声称等待能解决所有情况。
不要将打开实验 App 放在截屏前，也不要增加“保存到相册”“获取最新照片”。

**这一关过不了，就先停在截图路径排查，不必继续安装或开发。** 官方支持隐藏控制中心和运行快捷指令，不等于保证每个 App 的每个页面都能被正确截图。

## Mac 安装实验 App

环境与主工程一致：Xcode 26.2 或更新、iPhone iOS 26.2 或更新。实验本身没有外部包依赖。

1. 打开本目录的 `CaptureLab.xcodeproj`，不要改正式版 `Butler.xcodeproj`。
2. 选择 `CaptureLab` scheme 和你的 iPhone。在 Signing & Capabilities 选择自己的开发团队；预填的是仓库现有团队。如需要改安装标识，只改实验工程，**绝不要改成正式版的 `com.anvalar.Butler`**。
3. 按 Xcode 提示开启手机开发者模式、信任开发者并运行。无需 TestFlight。
4. 主屏幕应多出“小当家采集实验”，正式版仍在；先打开一次，再到快捷指令搜索动作。

只做编译检查（不发布）的命令，在仓库根目录执行：

```sh
xcodebuild -project experiments/CaptureLab/CaptureLab.xcodeproj \
  -scheme CaptureLab -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/ButlerCaptureLabBuild CODE_SIGNING_ALLOWED=NO build
```

## 配置实际采集按钮

复制截图验证快捷指令，删除“快速查看”，换成实验 App 的 **接收截图并开始实验录入**：

1. 隐藏控制中心。
2. 截屏（仅在上一阶段证明需要时，在前面加等待）。
3. 接收截图并开始实验录入：
   - 截图 = **第 2 步的截屏结果**。
   - 录入方式 = **打字**。

命名“采集实验·打字”，放到控制中心。再复制一份，仅将方式改为“语音”，命名“采集实验·语音”。这是两种输入方式，不是用途分类；不要把参数设为“每次询问”，否则会额外弹一步。

找不到动作时，确认安装的是实验 App 并打开过一次；关闭重开快捷指令，再在“App”列表里找“小当家采集实验”。若仍没有，记录 iOS/Xcode 版本与搜索结果，不能用“打开 App”代替后宣称图片传递成功。

## 应看到的交互

1. 在其他 App 下拉控制中心，点采集按钮。
2. 系统隐藏控制中心并截图，然后打开实验 App。
3. 输入页已有刚才的截图。打字模式聚焦文字框；语音模式尝试开始识别，**看到“正在听”后再说话**。第一次需授予麦克风和语音识别权限，必要时授权后点“开始说话”重试。
4. 自由输入，例如同样一张商品图可以说“记录我已购买的物品”，也可以说“周五提醒我考虑是否购买”，实验只原样保留文字，不预选分类。
5. 语音点停止、核对文字，再点“保存到本机实验记录”。打字时也可直接点键盘上方的“保存实验记录”，不用先滚动到底部；要删除草稿时可先点“收起键盘”。显示保存成功后，可打开记录查看图片与文字。
6. 用底部横滑/应用切换器返回原 App。**左上角是否出现系统返回提示、返回哪一个 App、原页面是否仍保留，都是待测项，不承诺自动返回。**

未保存就离开：麦克风停止，已识别/输入文字暂存；再打开不会自动继续录音。没有被识别出来的话无法恢复。
退出或锁屏时，应检查橙色麦克风指示是否消失。保存失败不能当作成功，输入保留在页面，点保存重试。

## 真机验收与去留

先用不含支付密码、验证码等敏感信息的页面。若录屏影响语音音频，另用设备计时，并将录屏与非录屏结果分开。
截图和录屏只需保留必要区域，分享反馈前遮住订单地址、联系人等信息。

| 场景 | 通过标准 |
| --- | --- |
| 四种来源各 5 次 | 图片都是当时原页面；0 次错图、串图或控制中心画面 |
| 冷启动、后台已打开、实验记录详情页各进入 | 都直接进入本次录入，不被旧页挡住 |
| 同一张图表达两种不同意图 | 保存的文字与当次输入一致，不自动分类、不替换意图 |
| 首次语音授权、拒绝权限、无设备端识别 | 有明确说明；打字、截图和草稿仍可用 |
| 已授权语音、连续两段语音、语音后修改文字 | 首句不漏、旧文字保留、停止后可修改；不自动保存或执行 |
| 锁屏、切后台、电话中断、回到输入页 | 停止麦克风，保留已转成的文字，不自行恢复录音 |
| 中文输入法、多行长文字、小屏幕、大字号、深色 | 内容能看清，键盘不挡住必要操作，能停止/保存/删除 |
| 空意图 | 不能标记为完成；仍可删除草稿 |
| 未完成时再触发或连续点击 | 明确拒绝新请求，原截图和文字不变 |
| 强制关闭后重开 | 草稿和完成记录都能恢复；不自动录音 |
| 保存后继续第二次、删除任一记录 | 图文对应；不影响另一条记录 |
| 返回淘宝/微信 | 记录实际返回手势、返回目标和页面是否保留，不把系统左上角返回当作必有能力 |
| 实验前后打开正式版 | 原有数据与常用功能保持原状 |

每次至少记：手机/iOS/来源 App 版本、页面类型、打字或语音、冷/热启动、等待时长、截对与否、点按钮至能输入的秒数、返回是否保留原页、异常。
建议先看 20 次试验中的中间耗时和最慢耗时，而不是只看最快的一次。可暂以熟练操作多数在 3 秒内进入可输入状态作为体验目标，**不是平台保证**。

- 截图稳定、输入快、返回不打断原任务：再讨论迁入正式版通用对话、使用正式语音组件和 AI 处理。
- 图片可靠但太慢：继续比较等待时间、打字/语音入口和少量交互改进。
- 经常截错、无法稳定交接或返回成本过高：停止这条路线；分享菜单仍可作为独立备选。

## 自动检查的边界

```sh
swift test --package-path experiments/CaptureLab
```

它运行真实存储和接收模型的测试，覆盖重复接收不覆盖、图文配对、自由意图、大小边界、未完成文件不发布、损坏记录不静默忽略、重启不自动录音、迟到文字不串入新记录、保存失败后重试。
测试图片使用不同字节来检验存储，不是图片解码测试；SwiftUI、系统快捷指令、图片解码、权限弹窗和真实麦克风仍需 Apple 运行环境检查。模拟器也不能证明在淘宝/微信上的全程可用。

## 交接给其他工具验证（2026-10-05）

### 需求与本次实现的边界

用户希望在其他 App 看到商品、订单等信息时，尽量少切换、少选图，就能把材料和**这一次的真实意图**交给小当家。同样的截图可能对应记账、记录物品、提醒、比较商品等完全不同的意图，因此实验不预置用途分类，也不自动决定下一步。

本次只实现可废弃的独立采集实验，不是将入口合入正式聊天。控制中心使用**系统的快捷指令控制**，而非新增自定义 Control Widget。截图来自系统快捷指令，实验 App 本身没有跨 App 截屏或读取任意 App 数据的能力。

## 丢弃实验

删除 iPhone 上的“小当家采集实验”（选择删除 App，不是仅移出主屏幕），再删两个快捷指令和控制中心按钮即可。它的本机记录随 App 删除；正式版不受这个容器的删除影响。仓库内实验仅在本目录，未修改正式工程；不需要改正式版数据库。不要为了清理实验而删除正式版小当家。
