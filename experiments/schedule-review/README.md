# 日程总览设计决定

2026-10-05，用户选择方案 B：连续清单 + 月历浮层定位。

- 默认清单可以直接前后滚动，历史不需要切换模式。
- 日期作为全宽分组标题；不用占宽的日期侧栏或大块日卡片。
- 没有常驻或折叠式周日期条。日期入口打开月历，选日只定位，不过滤其他日期。
- 右上角仅保留“日期”按钮；回今天放在日期面板内。
- 只有明确选择时间段才限定结果，并提供可见的“取消限定”。
- 已知日历事件显示结束时间；不把提醒推算成一段占用时间。
- 每日提醒归属具体日期，不固定在顶部。不冒充历史完成记录。
- 排除方案 A 的折叠周条、方案 C 的常驻周条，以及此前近期/周/月模式切换。
