# 物品页设计约束

2026-10-07 用户真机截图反馈后的设计：

- 物品页直接展示物品，一件库存记录一张圆角矩形卡片；不要用类别、位置或“只记数量”等内部状态做巨大入口卡片，也不使用井号来代表物品。
- 卡片优先显示已有照片，无照片用对应物品或品类图标；名称为主体，数量、类别、位置、到期或计划日期为简短辅助信息。数量管理方式不作为卡片标题。
- 卡片直接打开物品详情。不同批次保留各自的数量与日期，不因名称相同而合并。
- 物品多时用懒加载网格、搜索和分类/位置筛选查找；图片缩略图在后台生成，避免滚动时同步解码原图。辅助功能大字体使用单列。
- 保留已处理记录入口。筛选与搜索只影响显示，不修改库存资料。

2026-10-07 紧凑布局反馈补充：

- 保留“分类 / 位置 / 到期”的分组能力，按相应维度展示小节。每个小节仍直接展示物品，单一小节不加重复标题。入口以最新的更多菜单设计为准。
- 搜索收在右上角放大镜里，点开才显示输入框；不常驻占据一整行。列表 / 网格切换与分组方式独立，记住用户选择。
- 卡片图标为小缩略图，不再占据整块大图区域。名称和状态按实际内容占高；没有日期就没有日期占位行，禁止为了行高一致添加空文字。

2026-10-07 顶栏协调性反馈（优先于之前的顶栏布局）：

- 使用系统导航栏和系统返回按钮，标题“物品”；去掉自定义整块 `.bar` 背景和自制大返回圆钮。
- 右侧仅有搜索与更多两个系统工具栏按钮，由系统统一尺寸与材质。不要把分段选择或独立的列表切换按钮直接挤在顶栏。
- 更多菜单里分为“分组方式”（分类 / 位置 / 到期）和“显示方式”（网格 / 列表），选中状态由 Picker 标示；两种偏好继续独立保存。

2026-10-07 搜索展开反馈（优先于之前的搜索呈现方式）：

- 禁止搜索 popover 或在标题上叠加大输入框。点击搜索后隐藏原导航行，在同一顶部安全区域用 44pt 高的搜索框和“取消”替换，不增加整块背景。
- 输入框出现时自动获得焦点并弹出键盘，物品实时筛选。清除只清空关键词；取消结束焦点、清空查询并恢复原标题/按钮。键盘搜索键收起键盘但保留结果和搜索框。
- 未搜索时保持用户已认可的系统返回/标题和搜索/更多布局。搜索状态不改变分组与列表/网格偏好。

2026-10-08 滚动背景与搜索动效反馈（优先于之前的系统导航栏约束）：

- 物品页顶栏保持固定高度，浏览与搜索共用同一布局位置；禁止搜索时切换系统导航栏显隐或增删顶部安全区，避免标题上移、内容跳动。
- 浏览态延续左侧返回/物品、右侧搜索/更多的布局与系统玻璃材质；所有图标按钮使用 44pt 点击区域。搜索态仅在同一行原位淡入淡出，减少动态效果开启时直接切换。
- 不显示整块顶栏底色或分割线，不随滚动切换背景；滚动内容裁切在顶栏下方，并隐藏顶部滚动边缘效果。清单和顶栏共用整页背景。

2026-10-08 搜索过渡细化（替代单纯整栏交叉淡化）：

- 保持当前搜索最终布局与固定行高。使用同一个玻璃胶囊和放大镜，从右侧工具区连续伸展到搜索位置，收起沿原路径返回；不销毁重建两套玻璃背景。
- 形变约 0.38 秒、无回弹；原标题和更多先淡出，输入提示/取消在展开中段淡入，文本裁切跟随展开边界。键盘在展开约 0.12 秒时开始出现，延迟焦点任务必须在取消/离开页面时自动取消，避免晚到的键盘。
- 开启“减少动态效果”时直接切换并立即聚焦。顶栏和清单不产生位移，不增加滚动底色。

2026-10-08 浅色卡片对比度修订：
- 物品网格/列表卡片在浅色模式使用清楚可辨的浅灰底、柔和灰色细描边和轻阴影，不能继续只用透明白底加白描边（在近白页面上看不见）。
- 深色卡片沿用用户认可的现有玻璃底色与边缘，修改只作用于物品卡片，不全局加深其他页面。

2026-10-08 真机色彩纠正（覆盖上条浅灰底要求）：
- 浅色卡片保留透明白色材质，不加蓝灰或其他有色整块底色；辨识度通过中性灰细边和轻阴影改善。深色保持不变。
