# 首页交互约束

用户确认的设计取舍（2026-09-29）：

- 左右滑动仅在安排清单区域逐日翻看，允许过去和未来；禁止把它实现成整个首页的日期模式切换。问候、实时建议、天气、顶部入口和底部摘要始终保留，不因滑动隐藏或重建。
- 翻日与任务行点击必须互斥。拖动一旦成立，本次松手不得打开详情；不足以翻页的拖动也不能变成点击，下一次真正轻点应立即有效。竖向拖动交给页面滚动，进入详情后停用首页翻日，返回手势不能更改所浏览日期。
- 左上角恢复显示今天的日期与星期，点击打开月历（2026-10-07 用户最新纠正，覆盖同日图标方案）。安排区左侧今天叫“今日安排”，右侧留空；其他日期显示具体日期与星期，右侧只提供完整文字“回到今天”。不显示左右箭头，继续用卡片滑动翻日；月历选日同样只改变清单（2026-10-07 安装后用户最新修订）。
- 翻日连续跟手：左滑看后一天，右滑看前一天；松手继续当前位移或平滑回位，不能先归零再重新入场。安排区标题反映当前日期；回到今天按目标日期相对当前日期确定方向；月历跳日轻微淡入。清单长短变化平滑调高，最终完整显示；减少动态效果用淡入。禁止沿用上一轮动画方向。
- 天气来源不能占用管家卡片空间；首页不显示来源标识或温度。左上角用简短口语描述当前天气或接下来的变化，不局限于“晴/雨”；点击进入天气详情。影响已知出行或户外安排时，自然融入管家正文，说明影响和准备，不与小字机械重复；具体时段须有逐小时预报，目的地须独立查询，不能拿本地天气替代。
- 清单完整显示，不随意截断、折叠；已完成记录也保留可见状态。
- AI 建议后台更新，更新状态在整张卡片右上角靠右，不紧挨天气；不因网络请求禁用当前操作，不在用户触碰卡片后替换其内容。
- “先放放”先让用户选择时间，不默默替用户决定时长。清楚区分首页建议暂缓与任务通知延迟。
- 不添加首页即时撤销条或撤销弹窗；状态纠正集中在任务管理完成并留历史。
- 管家卡片不再显示“其他”“其他安排”或额外对话/详情入口（2026-10-06 用户改定）。只保留直接处理事项的快捷操作，居中排列；放不下时居中换为纵排。无须处理时不放按钮。统一从底部语音或打字回应、纠正或新增事情；首页入口携带当时整张提醒，不默认指向快捷按钮的单一对象，保留通用对话和草稿。
- 沿用现有玻璃主题；水晶球固定，不再随滚动掉落/摊开。水晶球的专属约束见 ../../Design/AGENTS.md。

对话面板统一规则（用户确认，2026-09-29）：
- 全 App 只有一张从底部升起的对话面板，不另做弹窗或清单面板。按住水晶球说话后停在约 3/4 高（用户认为半高显示内容太少），顶部保持原页面；要打字（轻点水晶球、点输入框）时全高。往上拉看完整对话，往下拉收起，原页面状态不变。
- 管家列出的东西只以对话里的清单卡出现；× 和“去掉某样”只从清单去掉，不改库存。批量改位置/分类必须经过确认卡。
- 左上角日期文字不加玻璃底和边框，保留44点点击高度；安排标题为纯文字，不重复提供下拉入口。
- 天气详情是带手柄的上拉面板，无“完成”按钮、无“手机定位”标题；Apple Weather 标识小号放在最底部。半高/全高共用系统面板材质背景，不把 GeometryReader 页面背景叠在滚动区内，避免半高浮动面板右侧露缝（2026-10-07 修订）。
- 日期面板只有月历（2026-09-29 用户改定）：点日期即看那天的清单；不再有“跳到指定日期”“查看选定日期”“回到今天”“日程总览”“全部任务与历史”。任务与历史只在设置“提醒与日程”里。
- 清单标题今天叫“今日安排”（2026-10-06 用户改定）。首页底部只有一行“日程总览”（副标题带这周还有几件），物品只从右上角图标进入。
- 今日安排的任务行用左侧圆圈直接完成，长按有稍后提醒/暂停/取消。
- 管家提醒是“今天的总览”（2026-09-30 用户纠正）：概括今天有几件什么安排（合并同类，时间只说大概），再点出最需要处理的一件；不复述车次、时间、地点等清单里已有的细节，也不把任何一件从清单里拿走。按钮只给需要处理的那件；有安排但无需处理时只有总览。

日程总览（2026-10-05 用户最终选定方案 B，取代此前近期／周／月切换）：
- 日期标题不使用矩形材质底色条（2026-10-07 用户纠正）；融入页面背景，用字重和留白区分分组，保持连续浏览的空间感。
- 不显示“未包含系统日历”；只有已打开系统日历却读不到或正在读取时才提示。不放“查看更早/更晚的安排”按钮（点了内容加在屏幕外，看起来没反应），滑到两端自动续载（2026-10-07 用户纠正）。
- 默认定位今天，可以直接向前滚动看过去、向后看未来；分段加载，不要求先切换周或月。日期用全宽分组标题，直接显示时间和完整事项，不加大块日卡片、常驻周条或成段操作说明。
- 右上角只保留日历图标（无障碍名称“选择日期”），不显示“日期”文字或“今天”按钮。图标打开月历底部面板，可翻月及选择年月；选一天只定位，仍可继续看前后安排。只有明确选择时间段才限定结果，提供“取消限定”；不切换首页日期。
- 首页“本周”指今天至周日，不用未来七天冒充本周。每日提醒在各自适用日期下折叠，不固定在顶部；已完成记录保留可见，但不计入安排数量。跨多天的同一日历事件单列并标明完整起止，定位到事件期间时放在目的日期下，不合并不同重复实例。
- 日历事件显示真实结束时间，不给提醒虚构占用时长。自选范围每次最多366天（含结束日）。系统日历未开启、未授权、尚未读取时简短说明，不冒充已读且没有安排。

2026-10-07 最新修订：总览页面标题恢复为“日程总览”，右上角改为日历图标；首页底部“日程总览”入口不变（安装后用户最新修订）。不为日期定位添加接近一屏的底部占位；短清单不允许滚成一大片空白。提醒正文避免内部数据分类、生硬搭配和空泛劝慰，空闲时一句自然说明即可。

2026-10-08 日程总览日期抽屉重设计（覆盖此前总览时间段筛选约束）：

- 日期抽屉只负责定位某一天，点选后直接收起并跳转，总览仍能前后连续浏览；移除“选择时间段”、开始/结束日期和“取消限定”等交互，不影响首页日期。
- 不放关闭叉号，使用抽屉手柄/下滑关闭，并保留辅助功能逃逸关闭。标题旁提供“回到今天”，底部不另设操作区。
- 高度按月历实际内容测量，随月份行数和字体适配，不固定 540pt、不允许无意义的全高空白。空间不足时内容可以滚动。
- 月历使用系统面板材质，避免把全页几何背景放在抽屉内。选中日期使用明确的 label/systemBackground 反色，不能让背景的 .primary 继承反色前景。年份按字面显示，不加千位逗号。
